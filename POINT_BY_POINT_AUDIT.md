# Сверка калькулятора с Правилами № 2330

Срез: 29.09.2026. Основной текст: [Правила № 2330](https://www.consultant.ru/document/cons_doc_LAW_434753/0f3a9ac1b53968ba1a801a920535924bcfcab577/). Вторичная проверка сценариев: загруженные Анной «Карта законодательства», занятия 2 и 3, «Инструкция по алиментам 2026». Материалы помогают находить сценарии, но при расхождении применяется текст действующих Правил. Статус «есть» означает лишь наличие соответствующей ветки в прототипе; не означает юридическую готовность к продаже.

## Пункты 1–30: право, сумма, подача

| Норма | Состояние | Что добавить и как спросить без длинной анкеты |
| --- | --- | --- |
| 1–2: заявитель, ребёнок, беременная, гражданство и постоянное проживание | Частично: заявитель и каждый ребёнок отмечают гражданство/проживание; беременное заявление отсутствует | В начале выбор «на ребёнка / по беременности / оба». Беременность: дата постановки на учёт, срок на тот день и на дату подачи, прогноз родов. Иное гражданство супруга само по себе не отказ. |
| 3: доход на человека; новорождённый в 6 месяцев; продление многодетным | Частично: доход, сценарий новорождённого, однократные 10% | Новорождённому показывать отдельный путь без обычной оценки и проверять принятое решение СФР; статус многодетной семьи подтверждать отдельно. |
| 4 и 8: орган субъекта и территориальный ПМ | ПМ 2026 подключён, региональные дополнительные условия не собраны | После выбора региона предупреждать о неизвестных местных условиях; каталог актов субъектов для таких условий составлять отдельно. |
| 5–7: ступени для беременной и ребёнка | Детская ступень предварительно есть; беременной нет | Расчёт беременной от ПМ трудоспособных, при сравнении 50/75 учитывать 8 месяцев; если обращаются также на детей, учитывать обе назначаемые выплаты в сравнении по правилам. |
| 9–17: индексация и периоды назначения | Новорождённый/возраст частично | Выводить месяц начала выплаты, 12-месячный срок и прекращение в 17 лет; для беременности учесть прекращение, роды, раннюю постановку и полный месяц. Не путать срок назначения с доходным окном. |
| 18–20: способы подачи и доставки | В продукте нет | В отчёте короткий маршрут «Госуслуги / МФЦ / СФР», без запроса банковских реквизитов. |
| 19¹: беззаявительное назначение следующему ребёнку | Только подсказка | Спросить, пришло ли решение после рождения; если нет, показать проверку в СФР и возможность заявления в шестимесячный срок. |
| 20¹–20⁵: место пребывания/фактического проживания | Ветка адреса и подтверждения добавлена; проверка документов отсутствует | После выбора временного/фактического адреса уточнить документы; без них результат остаётся неопределённым. |
| 21–22: последняя выплата, несколько детей | Частично | Для отдельных заявлений нужны собственные даты и окна; нынешний календарь сравнивает одинаковую дату. |
| 23–30: межведомственные сведения и документы | Не автоматизируется самим сайтом | В отчёте персональный список документов только для отмеченных ситуаций, сроков и источников; не запрашивать паспортные данные ради расчёта. |

## Пункты 31–46: отказ и состав семьи

| Норма | Состояние | Необходимая ветка |
| --- | --- | --- |
| 31(а, г): смерть, 17-летие | Есть по точной дате | Сохранять дату события для прогноза. |
| 31(б): доход выше ПМ | Частично | Подключён ПМ 2026 по местности; пока не все доходы и изменения по годам. Особые временные исключения для отселённых лиц — отдельная ветка, не общий отказ. |
| 31(в, д, е): неполнота сведений, документы и доработка | Нет как процесс после подачи | Отдельный список «что уточнить / где получить / срок»; не называть неизвестные данные нулём. |
| 31(ж): действующее назначение другому представителю | Частично | Сверять каждого ребёнка и решение суда, при совместной подаче учитывать последний месяц. |
| 31(з): недвижимость | Частично | По объектам уже есть квартира/дом отдельно, земля, доли и исключения. Для неподтверждённой доли, господдержки, непригодности и ареста выводить проверку документа, не уверенное «проходит». |
| 31(и): транспорт | Частично | Подтверждать регистрацию, год, мощность, право собственности, арест/розыск, льготу по каждому объекту. |
| 31(к): вклад | Частично | Порог процентов за применимый налоговый год, закрытие за шесть месяцев и номинальный счёт; при неизвестном годе оставлять неопределённость. |
| 31(л): 8 МРОТ | Частично | Для каждого взрослого отдельно; причина по месяцам и подтверждение, один льготный взрослый в многодетной семье, отдельная беременность, учёт ЦЗН не более шести месяцев. Переходные исключения по новым субъектам и 2027 году версионировать. |
| 31(м): прежняя мера поддержки больше нового пособия | Вопрос о наличии добавлен; сравнения сумм нет | При «да» собрать получателя, сумму, период и вид, сравнить суммарно с рассчитанной новой выплатой. До проверки результат неопределённый. |
| 31(н): утратил силу | Не нужен для 2026 | Исторические правила потребуются лишь для старых дат обращения. |
| 31(о): подтверждение места пребывания | Условный вопрос есть | Подсказать возможные документы и сроки, если подтверждения пока нет. |
| 31(п, р): дееспособность и родительские права заявителя | Нет | Уточнение лишь при особом статусе: решение суда о дееспособности и правах в отношении конкретного ребёнка; затем юридический флаг по каждому заявлению. |
| 31(с): будущая редакция с 01.04.2027 | Нет | Вопрос о способе и дате приобретения гражданства только для месяцев после вступления нормы; проверить исключения. До этой даты не блокировать. |
| 32–44: сведения, сроки, решение, посещения беременной, прекращение выплаты | Частично/нет | Это отдельная страница «После подачи» с датами, документами и действиями, а не дополнительные обязательные поля первого экрана. |
| 45–46: состав семьи и исключения | Частично | Взрослый 18–22 лет очно и без брака входит; его доходы и имущество тоже проверяются. Расчёт ступени с таким членом семьи исправлен. Статус супруга по п. 46 уже есть; нужны даты изменения статуса и документы. Единственного опекуна теперь спрашиваем прямо. |

## Пункты 47–55: входящие доходы и исключения

| Норма | Состояние | Поля или подсказка |
| --- | --- | --- |
| 47(а–г): работа/ГПХ, пенсии и пособия, стипендия, алименты | Частично | Доход отдельно по человеку и периоду; ГПХ, больничный и вознаграждение приёмной семьи не терять в общей зарплате. Алименты делить по обязательствам и вторым родителям. |
| 47(д–ж): правопреемники, довольствие, общественные обязанности | Частично | Добавить виды в список галочек; для дохода ребёнка проверить исключение 52¹. |
| 47(з–м): ценные бумаги, вклады, ИП/частная практика, продажа/аренда, авторские | Частично | Налоговый год, расходы по операциям с бумагами (п. 51), расходы ИП на УСН «доходы» при подтверждении (п. 50), налоговая база продажи. |
| 47(н–с): самозанятость, содержание судьи, увольнение со службы, зарубежный доход, выигрыши | Частично | Добавить редкие варианты через «Другие поступления»; иностранную валюту пересчитать по курсу ЦБ на последнее число 12-го месяца окна (п. 55). |
| 48–52¹: окно, разовая выплата, алименты, налоговый год, доходы детей | Частично | Окно и БиР реализованы; Росстат для алиментов вручную и годовая публикация не автоматизированы. Зарплата несовершеннолетнего исключается при подтверждённой учёбе шесть месяцев. |
| 53(а–ю): неучитываемые поступления | Частично | Уже есть детское единое пособие по конкретному заявлению, номинальные счета и подсказки. Сделать отдельный перечень с галочками для маткапитала в предусмотренных случаях, соцконтракта, вычета НДФЛ, помощи при ЧС, выплат по уходу, компенсаций, целевых и иных исключений. Для спорного вида — «проверить основание», не вводить в общий доход и не исключать автоматически. |
| 54–55: сумма до налогов и валюта | До НДФЛ есть; валюты нет | Спросить валюту только при зарубежном доходе, сохранить сумму и дату нужного курса. |

## Порядок реализации

1. Сначала убрать ложную уверенность: неполные данные, особые условия региона, спорные документы и варианты 31(м, о, п, р) переводить в «нужна проверка».
2. Затем закрыть денежные ветки 47 и 53, несколько алиментных обязательств, беременную выплату и 18–22-летних членов семьи.
3. После этого — контрольные дела с ручной оценкой специалиста на граничных датах, редакции норм по месяцу обращения, данные 2027 года и автоматическое отслеживание источников.

Справочник законов Анны охватывает и другие пособия. В этом репозитории перечислены только нормы, влияющие на калькулятор **единого пособия**; остальные выплаты становятся вопросами о доходе, исключении или сравнении по п. 31(м), если применимы.
