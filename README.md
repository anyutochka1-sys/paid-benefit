# Платный калькулятор единого пособия — разработка

Это отдельный проект. Существующие бесплатные сайты в других репозиториях не изменяются.

## Текущее состояние

Прототип анкеты и отдельных проверок: расчётный период, уважительные причины отсутствия дохода, состав семьи и исключение супруга по пункту 46, недвижимость и транспорт, источники дохода с выбором галочками, три режима ввода зарплаты, алименты, вклады, единое пособие и демонстрация ступени 50/75/100%. **Нельзя использовать как готовое заключение о праве на пособие**. GitHub Pages и оплата пока не включены.

Для зарплаты можно указать одну постоянную сумму и период, разные суммы по месяцам либо общую сумму одного 12-месячного окна. Последний вариант не даёт достоверного прогноза. Пустое поле не трактуется как ноль. Пенсии, пособия, выигрыш и прочие регулярные поступления вводятся по сумме и месяцам; ИП, аренда, продажа имущества, ценные бумаги и авторский доход — по налоговому году. Прожиточный минимум 2026 года подставляется из снимка официальной таблицы СФР от 29.09.2026. В ней 91 субъект и 354 уникальные строки местностей, восемь точных дублей в исходной таблице убраны. Для девяти субъектов с несколькими строками выбор местности обязателен, если значения отличаются. Для 2027 года ПМ пока не подставляется, ступень не выводится. Перед публичным запуском снимок нужно повторно сверить с СФР.

Доходы детей вводятся отдельно с привязкой к ребёнку и месяцу. Зарплата несовершеннолетнего и компенсация за выполнение государственных обязанностей исключаются по пункту 52¹ только при подтверждённом очном обучении не менее шести месяцев в расчётном периоде. Другие доходы ребёнка оцениваются отдельно; неоднозначный месяц 18-летия требует точной даты поступления.

## До запуска

- Полная матрица доходов и исключений, включая алименты, предпринимательство, продажу имущества и проценты по вкладам по налоговому году.
- Все виды имущества, основания исключения, подтверждающие документы, даты приобретения и выбытия.
- Заявитель и дети: гражданство, проживание, беременность, ранняя постановка на учёт, действующее пособие, продление многодетным, правила с 01.04.2027.
- ПМ за годы, кроме 2026-го; повторная сверка таблицы СФР после официальных изменений, официальные данные Росстата для алиментов, годовые МРОТ и ревизии нормативных данных.
- Версионирование норм по дате заявления и проверка специфики региона; проверенные контрольные случаи специалистом.
- Защищённый сервер для подтверждения оплаты Robokassa и выдачи одноразового результата. Пароли магазина нельзя публиковать в статическом сайте.
- Решение по хранению чувствительных данных семьи и политике обработки данных.

# Изменения в расчёте доходов семьи

Выплачивавшееся единое пособие вводится отдельно с привязкой к ребёнку и месяцам. При общем заявлении на нескольких детей предыдущие выплаты на них исключаются; при отдельных заявлениях пересчитывается каждое заявление. Доходы по алиментам вводятся отдельно от зарплаты. Для новорождённого при действующем назначении на старшего показывается возможность назначения по последнему решению без новой оценки (до шести месяцев со дня рождения). Эти проверки предварительные; источник зарплаты Росстата и сложные варианты алиментов требуют дальнейшей автоматизации.

Пособие по беременности и родам вводится отдельной разовой суммой, месяцем начала начисления и количеством месяцев. Стандартный пример — 5 месяцев, продлённый срок уточняется по документу. За каждый месяц обращения учитывается только доля, попавшая в доходное окно. Минимум 8 МРОТ теперь сравнивается с указанным подходящим доходом отдельно для заявителя и супруга; это не заменяет остальные обязательные проверки.

Семейное положение заявителя выбирается отдельно от наличия второго родителя у ребёнка. Статус «никогда не состояла в браке» и повторный брак не запускают условный минимум алиментов; фактически поступившие деньги по ним по-прежнему вводятся. Для разведённого отдельно различаются суд, приказ, ФССП, нотариальное соглашение и неоформленные алименты. Нотариальная сумма берётся из соглашения, даже если фактически перечисляли меньше.
