# Матрица проверки единого пособия

Дата сверки: 29.09.2026. Основная норма: [постановление № 2330, Правила](https://www.consultant.ru/document/cons_doc_LAW_434753/0f3a9ac1b53968ba1a801a920535924bcfcab577/). [Действующая форма заявления](https://www.consultant.ru/document/cons_doc_LAW_434753/a6c2d95913ef4085152dc43a910fb6a4535e5644/) разделяет сведения на обстоятельства на дату подачи и за расчётный период. Это разные временные измерения в модели.

## Сверка каждого основания отказа из пункта 31

| Подпункт | Проверка | Состояние и следующий слой |
| --- | --- | --- |
| а | Смерть ребёнка, на которого подано заявление | Добавлены дата смерти, исключение из состава семьи и невозможность подачи после этой даты; поступления на такого ребёнка требуют раздельной атрибуции |
| б | Доход на человека выше ПМ | Прогноз по месяцам и ПМ 2026 по выбранной местности; не все виды дохода и годы ПМ подключены |
| в | Недостоверные/неполные сведения | Не может быть определено калькулятором; показывать список неподтверждённых сведений |
| г | Ребёнку исполнилось 17 лет | Реализовано на дату каждого обращения |
| д–е | Документы и доработка в срок | Процедурные события после подачи; в отчёте нужен список подтверждений и сроков |
| ж | Пособие уже назначено другому законному представителю | Добавлены получатель, срок и судебное решение. Если заявитель уже получает выплату, учитываются последний месяц назначения и совместная подача на детей с разными сроками по п. 21 |

| м | Сравнение с ранее получаемыми мерами поддержки | Не реализовано; нужны виды и суммы прежних выплат |

Пункты 45–46 задают состав семьи на дату обращения и исключения. Доходы пунктов 47–52 и исключения пункта 53 сверять по каждому виду поступления: единое пособие на детей из текущего заявления, выплата на детей 17+, ряд целевых выплат, маткапитал, налоговый вычет, помощь при ЧС, социальный контракт, номинальный счёт подопечного и другие исключения. Пункт 54 требует учитывать заработок до налогов; пункт 55 — отдельный пересчёт валюты. Обычную зарплату и уже получаемое единое пособие сейчас обрабатываем, остальные виды не следует маскировать общей строкой без уточнения вида.

1. Сначала короткие вопросы «есть / нет». Уточнения показывать только для ответа «есть».
2. ФИО, паспорт и СНИЛС не нужны для математической оценки. Мы не повторяем всю форму Госуслуг.
3. Пустое число означает «не знаю», явный ноль — «дохода не было». Даты сохраняют историю для пересчёта всех 12 месяцев.
4. Быстрый итог действует только для одного окна. Для прогноза рекомендовать ввод по месяцам и каждому члену семьи.
5. Источники данных и понятное пояснение размещать рядом с вопросом. Доход по зарплате брать до НДФЛ; по вкладам — выплаченные проценты, не тело вклада и не только налогооблагаемую часть.
6. При недостатке подтверждённых данных не выдавать «пособие назначат». В отчёте показывать неизвестные факторы и возможное влияние каждого.

## Особые изменения по времени

- С 01.01.2026 минимум 8 МРОТ и новые правила уважительных причин.
- С 01.03.2026 расчётная база алиментов без суда/приказа или по нотариальному соглашению — применимые окончательные годовые данные Росстата по региону.
- Пункт 33: отсутствие сведений о втором родителе в записи о рождении, запись об отце по заявлению матери, смерть, объявление умершим или признание безвестно отсутствующим дают статус единственного родителя. Лишение свободы и лишение родительских прав второго родителя сами по себе этот статус не дают. Обстоятельства указываются отдельно для каждого ребёнка. Если дети в одном поле алиментов имеют разные статусы, общий расчёт помечается неопределённым до разделения обязательств.
- Лишение свободы самого заявителя или члена учитываемой семьи может служить уважительной причиной отсутствия дохода по пункту 31; лишение свободы отдельно проживающего второго родителя автоматически не даёт эту причину заявителю. Пенсию по потере кормильца нужно отражать в соответствующих доходах отдельно, если она учитывается для конкретного заявления.
- С 22.05.2026 специальное однократное продление многодетным при превышении ПМ не более 10% (в пределах указанного срока обращения); применяется к правоотношениям с 01.01.2026.
- С 21.07.2026 изменены некоторые проверки места проживания и ухода за нуждающимся родственником.
- С 01.04.2027 вступит в силу требование пятилетнего проживания в РФ в статусе гражданина для ряда заявителей с исключениями. Не применять до этой даты.
