## Принципы анкеты

1. Сначала короткие вопросы «есть / нет». Уточнения показывать только для ответа «есть».
2. ФИО, паспорт и СНИЛС не нужны для математической оценки. Мы не повторяем всю форму Госуслуг.
3. Пустое число означает «не знаю», явный ноль — «дохода не было». Даты сохраняют историю для пересчёта всех 12 месяцев.
4. Быстрый итог действует только для одного окна. Для прогноза рекомендовать ввод по месяцам и каждому члену семьи.
5. Источники данных и понятное пояснение размещать рядом с вопросом. Доход по зарплате брать до НДФЛ; по вкладам — выплаченные проценты, не тело вклада и не только налогооблагаемую часть.
6. При недостатке подтверждённых данных не выдавать «пособие назначат». В отчёте показывать неизвестные факторы и возможное влияние каждого.

## Особые изменения по времени

- С 01.01.2026 минимум 8 МРОТ и новые правила уважительных причин.
- С 01.03.2026 расчётная база алиментов без суда/приказа или по нотариальному соглашению — применимые окончательные годовые данные Росстата по региону.
- С 22.05.2026 специальное однократное продление многодетным при превышении ПМ не более 10% (в пределах указанного срока обращения); применяется к правоотношениям с 01.01.2026.
- С 21.07.2026 изменены некоторые проверки места проживания и ухода за нуждающимся родственником.
- С 01.04.2027 вступит в силу требование пятилетнего проживания в РФ в статусе гражданина для ряда заявителей с исключениями. Не применять до этой даты.
